### **About ReactiumMC**

ReactiumMC is an open-source organization dedicated to providing a stable, high-performance Java-based server software core for Minecraft: Bedrock Edition. Built as a lightweight, legacy-inspired solution, Reactium focuses on simplicity, native `.jar` plugin compatibility, and long-term project stability.

---

### **Key Projects**

* **[Reactium](https://github.com/ReactiumMC/Reactium):** The primary Bedrock Edition server software core built for performance, clean architecture, and easy plugin development.
